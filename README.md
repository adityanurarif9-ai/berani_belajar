# Berani Bicara

Aplikasi latihan public speaking untuk siswa SMP dan SMK. Siswa bisa membaca materi, memilih topik, latihan dengan timer, dan menilai hasilnya dengan rubrik. Ada kuis dan riwayat progres di browser.

## Cara menjalankan

1. Unduh atau clone repo ini, lalu buka `index.html` di browser.
2. Pilih **Latihan**, lalu nyalakan kamera dan mikrofon jika ingin merekam. Berikan izin saat browser memintanya.
3. Tekan **Mulai**. Setelah sesi selesai, putar ulang rekaman atau unduh hasilnya.

Aplikasi berjalan di browser. Rekaman diproses di perangkat dan progres tersimpan di browser yang dipakai.
